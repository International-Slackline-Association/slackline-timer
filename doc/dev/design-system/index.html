Design System · Slackline Timer · ISA

Telemetry

A broadcast-grade visual language for head-to-head speed racing, built on the International Slackline Association brand — teal, slate, and a warm orange-red accent on clean, light surfaces. Carries a strict green / amber / orange-red race-state language from IFSC speed climbing, with monumental tabular numerals as the hero of every screen.

Broadcast overlays

Transparent canvas, LAAX plate language: full-bleed backdrop dim, white-stroked translucent plates, tight condensed caps — survives over any live footage.

The LAAX plate treatment: an optional full-bleed --tl-overlay-backdrop dim (#231f20 at 60%) behind the composition, VS/photo panels as --tl-overlay-plate (30% white; empty name bars use --tl-overlay-plate-name, the names art's 35%) with a solid --tl-overlay-stroke-width (6px @1080p) white stroke, and display caps tracked tight (--tl-overlay-heading-tracking). White structural text keeps a per-text shadow; numerals read green-for-leader regardless of footage. The dashed rectangle marks the ~5% title-safe margin. Motion is state-driven only — slide-in on appear, win-flash on resolution.

TELEMETRY — palette derived from the International Slackline Association brand. Implementation lives in web/src/app/theme/: tokens.ts (TS source of truth), tokens.css (--tl-* custom properties for overlays & previews), theme.ts (telemetryTheme, light MUI theme). Full spec in doc/dev/design-system/design-system.md. Every value above is a real token.
